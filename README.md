## 🚀 What is this repository?

**Advance DSA Python** is a hands-on repository for learning and practicing **Data Structures and Algorithms (DSA) using Python**.

Instead of only reading theory, this repository focuses on **writing the code, understanding the logic, solving problems, and improving problem-solving skills**.

It brings together:

* 📚 Data structure implementations
* 🧠 Algorithm implementations
* 🔍 Searching and sorting
* ♻️ Recursion
* #️⃣ Hashing
* 🔗 Doubly linked lists
* 💻 LeetCode solutions
* 🐍 Python coding problems
* 📈 Continuous problem-solving practice

**The goal is simple: understand the logic → implement it → solve problems → get better.**

## ⏱️ Time & Space Complexity

For every algorithm, two important questions should be asked:

### Time Complexity

**How does the running time grow as the input grows?**

Common examples:

```text
O(1)        Constant
O(log n)    Logarithmic
O(n)        Linear
O(n log n)  Linearithmic
O(n²)       Quadratic
```

### Space Complexity

**How much additional memory does the solution need?**

Understanding complexity helps decide whether a solution is practical for larger inputs.

## 💡 The Main Idea

DSA is not about memorizing hundreds of solutions.

It is about learning to look at a problem and ask:

> **What is the right way to represent this data?**

> **What approach can solve this efficiently?**

> **What happens when the input becomes much larger?**

> **Can the solution be simplified or optimized?**

That problem-solving mindset is the real skill.
